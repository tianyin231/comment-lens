# 评论风向验收说明

适用版本：v0.3.2。当前支持小黑盒帖子评论，B 站评论、弹幕和直播尚未适配。

## 构建与自动验证

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
git diff --check
```

Windows 使用 `gradlew.bat`。测试不得依赖真实密钥或真实用户评论；HTTP 协议用 MockWebServer 验证。

主要检查：同文去重、全部已判断评论参与统计、正文与待判断内容不混入比例、旧请求不能串帖、最近 5 帖缓存顺序、缓存恢复后不重复判断、请求不带历史或父评论。

## 设备检查

1. 开启无障碍“使用评论风向”和悬浮窗权限，默认手动，不需要开启系统无障碍快捷方式。
2. 在小黑盒帖子手动分析，确认只读取正文及评论文字；昵称、点赞数、图片和推荐内容不参与情绪判断。
3. 开启自动后正常浏览，细条跟随本帖全部已判断评论更新，详情显示原文、情绪及置信度；帖文单独显示。
4. 累计超过 30 条后，确认最早评论仍在，比例包含全部已判断评论，详情可滚动查看全部内容。
5. 退出再返回同帖、重启服务，确认文字与结果恢复；已判断文字不重新请求 Jev。
6. 切换帖子后统计独立；缓存最多保留最近 5 帖，第 6 帖淘汰最久未访问的。

使用截图和应用自身状态检查，避免在无障碍采集运行时使用 `uiautomator dump`，以免测试工具影响服务连接。

## 长文章修复候选包的真机验收

以下是待执行步骤，不代表已在真实长帖上通过。记录设备型号、Android 版本、小黑盒版本、测试包 SHA-256、文章链接或可重复的进入路径；截图和日志应去除账号、密钥及不需分享的内容。

1. 在测试设备安装候选 debug APK，开启无障碍和悬浮窗权限。新云环境的 debug 签名可能与已安装包不同，无法覆盖时应使用独立测试设备或测试用户；卸载会丢失配置和本地缓存。
2. 停留在小黑盒首页、推荐列表、单卡片列表和搜索列表，确认细条不出现。打开正常短帖，确认细条与手动分析仍可用。
3. 打开真实长文章，先停在顶部正文、尚未显示评论的位置。确认细条出现，展开后显示本篇正文；对有标题及没有单独标题的长文分别检查。不要仅凭细条出现判定通过。
4. 手动分析当前屏幕，确认正文与可见评论内容正确，昵称、点赞数、推荐内容没有混入。开启自动后滚到评论区，确认新评论可加入；来回滚动，已读评论不重复计数，已有判断保留。
5. 快速在 A/B 帖间切换（包括同作者同标题、正文不同的文章），并在分析尚未返回时切帖、回首页或切到其他应用。新页面不能显示或写入旧帖评论、比例、结果或错误；返回 A 应恢复 A 自己的缓存。
6. 分别在读屏和分析进行时切换自动/手动模式，确认旧任务不会重新开启手动分析或继续以旧模式采集。相同 Activity/窗口内连续进入不同帖子也要检查。
7. 关闭再开启服务、返回缓存中的文章，确认结果恢复，已判断内容不重复发送。正文完全不在无障碍树、出现多个正文候选或读取失败时，不得把上一帖的状态沿用到未知页面。

若长文仍无细条，记录它是否有独立标题、所在位置（顶部/中段/评论区）、进入方式及上述环境信息。当前没有用户真机日志或指定复现文章；合成节点回归只能验证已知选择器与状态规则，不能证明所有小黑盒长文布局已适配。

## v0.3.2 原发布版本的历史验证范围

- 单元测试 41 项通过，debug APK 构建通过。
- MuMu 模拟器：68 条已判断评论在覆盖更新后完整恢复；详情与情绪条使用全帖统计。
- 同帖累计超过 30 条后仍保留原评论，退出返回与服务重启恢复已验证。
- 最近 5 帖淘汰顺序、缓存序列化、待判断队列与重复请求控制由单元测试覆盖。

当前验证不代表所有机型和小黑盒版本均已覆盖，也不包含正式签名包发布或 B 站适配验收。

## B 站视频链接开发候选

当前只提供链接检查及明确的获取阻碍显示。平台许可/接口核验及本轮结果见 [B 站接入核验](bilibili-link-analysis.md)，不能将单元测试通过视为真实评论获取通过。

2026-09-30 云环境：完整单元测试 113 项通过（本轮新增 46 项），lint 0 错误、22 条原有警告，debug 构建、签名与对齐检查通过。以下 UI 行为是后续检查清单，本轮没有运行 Android 分享事件或真机验收。

- 完整 HTTPS 视频链接、BV / av 编号、带跟踪参数的分享文字应规范化为同一视频目标；伪装域名、账号信息、端口、多目标、非视频路径和超长输入应拒绝。
- `b23.tv` 当前只识别，不能显示为已经解析或已验证的视频。
- 生产来源不可用时，必须显示实际读取 0、平台总数未知、实际排序未取得、楼中楼未读取、未分析与具体原因；即使已配置 Jev，也不发送评论或分析请求。
- 注入的合成来源测试需要覆盖前 N 条、跨页 ID 去重、同文不同 ID、排序不符、重复游标、无新增页、分页中途失败和取消。不能把有限回复预览或额外置顶项冒充完整顶层序列。
- Jev 测试验证同文请求复用但按评论 ID 统计，空文跳过、不完整响应拒绝、额度或限流错误后停止后续批次、保留已完成结果。
- 输入或分享目标改变、N/排序改变或页面销毁后，旧任务不得回填新界面。实际 Android 事件接线检查尚未执行，当前按源码审查记录。
