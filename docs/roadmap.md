## 不滑屏分析前 N 条评论

先核验各平台允许的获取方式和实际可获取范围，再决定方案。无障碍只能读取平台向系统暴露的节点，无法保证取得尚未加载的评论；评论总数和已读取数量必须分别表述，不能宣称抓取了全部评论。

需要确认：

- “前 N 条”的排序含义（热度、时间或页面展示顺序），以及是否包含楼中楼。
- 平台允许的接口、授权和访问条件；若无可用方式，应明确限制。
- 已加载但屏幕外的节点是否可读，以及不同应用版本的行为差异。
- 分页、去重、失败重试、速率限制与用户数据的本地处理范围。

当前实现不自动滑屏或翻页，不读取目标应用数据库，不修改或注入目标应用。新的获取方案需单独设计和验证。
